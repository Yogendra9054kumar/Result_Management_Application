# Result_Management_Application

A Python-based Result Management System designed to manage student academic records efficiently using SQLite database integration and a simple graphical interface.
This application allows users to add students, manage courses, store results, and view academic performance in an organized way.

# Features
📚 Course Management
👨‍🎓 Student Record Management
📝 Result Entry & Management
📊 Dashboard Interface
💾 SQLite Database Integration
⚡ Fast & Lightweight System
🖥️ User-Friendly GUI
